Team posts appear at the top of the Guides page straight away and open at /blog-post. Built-in guides are edited in this same editor; the first save converts a guide to the simple format (headings + paragraphs), and Reset restores the original completely.

Add a client review

Only add reviews the business has genuinely received (Google, WhatsApp, email). The reviews section on the homepage stays hidden until at least one review is visible here - nothing is ever invented.

Reviews on the site

Visa prices

Set a total price for a visa and it appears on that visa's page, its cards across the site, and in the assistant chatbot - in the currency you choose. Leave the amount empty for "confirmed in writing" (the current behaviour). Only publish prices the business has approved.

Content editor

Edit any text on the website, per language. Search for the current wording, change it, save - the site updates immediately, no rebuild needed. Editing English changes the original text; editing another language overrides its translation (machine translations you have not touched stay as they are).

Media library

Upload photos (JPG, PNG, WebP, max 6MB) and use their links in blog posts. Uploaded photos live on the server and survive redeploys.

Photos already on the website

Every photo the website already uses - copy its link or use it in a blog post or guide. These are part of the site itself, so they cannot be deleted here.

Contact details shown on the site

Email sending (SMTP)

When these are filled in, applicants are emailed automatically at every stage change and the team is alerted about new applications. For the brand mailbox, the login is the Google account behind info@visit-saudi.ae with an app password (smtp.gmail.com, port 587).

Payments

Online payment keys for the website checkout. Keys are stored on the server only - they are never shown on the website and never included in backups.

Ziina: the API key is set in the hosting panel (xCloud → Environment → ZIINA_API_KEY), not here. The same Ziina account is shared with dubaivisaportal.ae, so the webhook there must not be changed.

Backup & restore

Download one file containing every application, enquiry, blog post, review, price, content edit and setting (the email password is never included). Keep it somewhere safe - restoring it replaces the current data.
